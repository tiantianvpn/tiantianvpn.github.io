一、什么是 Quantumult X？

Quantumult X 是一款专注于网络规则分流与代理管理的高级工具。它的核心用途是：科学上网、网络加速、规则控制、流量监控、代理链路管理等。由于其强大的灵活性和稳定性，在 iOS 用户圈中广受推崇，尤其适合中高级用户或网络安全爱好者。

它不同于一般的 VPN 客户端，它更像一个小型的可编程网络路由器，你可以在里面设定谁走代理、谁走直连，甚至为不同的流量制定多级规则。这种“规则优先”的架构，让它在应对复杂网络环境时游刃有余。

二、为什么选择 Quantumult X？

在 iOS 平台上，类似的工具还有 Shadowrocket、Loon、Stash 等，但 Quantumult X 能脱颖而出，靠的正是其细腻的功能配置能力和稳定性极高的运行机制。

2.1 核心优势

  • 策略组支持：可以设置多个策略组（如自动选择、节点列表、负载均衡等）。

  • 脚本支持：通过 JavaScript 执行高级功能（如重写请求、广告拦截等）。

  • 流量分析：按时间、应用、节点等多维度进行网络使用统计。

  • 规则灵活：内建强大的“规则分流系统”，用户可轻松自定义规则优先级。

  • 轻量美观：UI 简洁，几乎无卡顿，后台运行稳定。

五、规则与策略组：玩转分流的关键

Quantumult X 的灵魂，在于分流规则与策略组配置。这是它与普通 VPN 最大的差异。

5.1 什么是策略组？

策略组是一个“逻辑集合”，用来指示某类请求要使用哪种连接方式。常见的策略组包括：

  • 直连（DIRECT）：不通过代理，直接连接；

  • 全局代理（PROXY）：所有请求走代理节点；

  • 节点列表：列出多个节点供用户选择；

  • 自动选择（AUTO）：根据延迟或负载自动切换节点；

  • 拒绝（REJECT）：拦截特定流量，常用于广告屏蔽。

5.2 自定义规则分流

你可以根据域名、IP、应用名等创建详细规则。例如：

plaintext
DOMAIN-SUFFIX,google.com,PROXY
DOMAIN-SUFFIX,baidu.com,DIRECT
PROCESS-NAME,YouTube,PROXY

这些规则将自动应用在访问过程中，实现精准控制。

✅ 小贴士：建议使用“规则分组 + GEOIP + DOMAIN”组合，可以最大程度地控制代理策略，防止误杀或漏判。

七、使用中常见问题与解决方案

7.1 Quantumult X 无法连接？

7.2 VPN 状态频繁断开？

  • 避免开启低功耗模式；

  • 设置中允许后台活动；

  • 尽量使用稳定节点，不建议使用公共免费节点。

7.3 如何重置 Quantumult X？

在设置页中选择“恢复出厂设置”，即可清除所有配置，回归初始状态。

7.4 能否在一个设备上安装多个版本的 Quantumult X？

官方并未推出多版本，因此只能安装一个。若需切换配置，建议保留多个 .qxconfig 文件，根据场景导入即可。

FAQ

Hiddify Next 是什么？
Hiddify Next 是基于 sing-box 的多协议代理客户端，适用于 Android、Windows 等平台。它整合了 Vless、VMess、Trojan、Hysteria 等协议，支持自动测速和订阅转换，是移动端非常流行的代理工具。
如何在手机上减少代理应用对电量的消耗？
关闭不必要的后台代理连接，减少实时测速或心跳频率，启用省电模式并限制流量统计与日志记录；对于常用站点设置直连策略，避免所有流量都走代理带来的持续网络负荷。
Netch 的规则代理与全局代理如何选择？
全局代理会将所有流量通过节点转发，而规则代理只针对指定 IP、端口或应用。用户可根据需求选择，以优化带宽利用和流量分流，确保不同应用的最佳体验。
Nekoray 如何实现节点延迟自动切换？
Nekoray 支持配置策略组（Policy Group），用户可设置 URL 测试或周期检测机制，根据延迟自动选择最优节点。此功能能提升稳定性，尤其适合多线路机场订阅用户。
Potatso Lite 的节点导入方式有哪些？
Potatso Lite 支持通过手动添加节点信息或扫描二维码导入节点。虽然不支持自动订阅更新，但对轻量用户来说，手动方式足够使用，方便在 iOS 设备上管理节点。
Mihomo 节点分组功能有什么优势？
分组管理可按延迟、地区或用途分类节点，并结合策略组实现自动分流。用户可快速选择最优节点，提高访问速度和稳定性，方便管理大量节点并优化维护效率。
Netch 全局与规则代理如何合理选择？
全局代理适合游戏或全局科学上网，将所有流量通过节点；规则代理仅对指定应用或 IP 走代理，可提高带宽利用率和访问效率，根据使用场景灵活选择模式。
Hysteria2 的多路复用对短连接有何优势？
多路复用允许多个短连接共享同一通道，减少握手延迟和资源消耗。适合高频短连接应用，如游戏和即时通讯，可提高吞吐量和连接稳定性，优化网络体验。
Mihomo 的日志功能如何调试连接问题？
Mihomo 日志可显示节点连接、请求延迟和错误信息。通过分析日志，可以判断节点是否不可达、TLS 握手失败或规则匹配异常，从而快速定位问题并解决。
Potatso Lite 是否支持 Vless？
目前 Potatso Lite 仅支持 Shadowsocks 和 Vmess 协议，不支持 Vless。但开发者正在逐步扩展功能，未来可能加入更多现代代理协议支持。
